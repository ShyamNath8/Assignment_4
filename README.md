Employee Scheduling System

This project implements a weekly employee shift scheduling application in two programming languages:  
-  Python
-  Go (Golang)

The application schedules employees across 7 days with 3 shifts per day (morning, afternoon, evening), respecting company rules and employee preferences.

---

 Features

- Each employee works at most 1 shift per day  
- Maximum of 5 working days per employee 
- At least 2 employees per shift per day 
- Automatic conflict resolution (alternate or next day assignment)  
- Bonus: ranked shift preferences supported in Python  
- Readable final schedule output

---

Requirements

- Python 3.8+  
- Go 1.20+  
- (Optional) VS Code with Python and Go extensions for easy running.

---

 Running the Python and Go Versions

 

 Run interactively:
- On VS Code run the following files
  
- python schedule.py
- schedule.go
